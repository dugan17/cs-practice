Рабочая папка - место, где находится файлы проекта и где ты вносишь изменения. Индекс - область, куда добавляешь изменения, которые хочешь включить в следующий коммит. Коммит - сохраненная версия изменений с описанием того, что было изменено.
Git - программа для контроля версий, которая отслеживает изменения в файлах и позволяет сохранять их в коммитах. GitHab - онлайн-сервис, где можно хранить Git-репозитории и работать над проектами вместе с другими людьми.
 Git status - показывет состояние рабочей папки и индекса: какие файлы изменены, добавлены или готовы к коммиту. Git diff - показывает изменения в файлах, которые еще не добавлены в индекс. Git diff --stage - показывает изменения, которые уже добавлены в индекс и войдут в следующий коммит.
