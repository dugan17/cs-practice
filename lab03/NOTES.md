## 2. Сравнение версий и поиск изменений
- Выполнил `git log --oneline --stat`: увидел список коммитов и количество измененных строк.
- **Чем отличается git diff от git show и git log:**
  - `git log` показывает историю коммитов (список).
  - `git diff` показывает разницу между двумя версиями файлов.
  - `git show` показывает информацию о конкретном коммите (автор, дата) и его изменения.
- Выполнил `git blame calc.py`: команда показала, кто и в каком коммите менял каждую строку.
