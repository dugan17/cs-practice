## 2. Сравнение версий и поиск изменений
- Выполнил `git log --oneline --stat`: увидел список коммитов и количество измененных строк.
- **Чем отличается git diff от git show и git log:**
  - `git log` показывает историю коммитов (список).
  - `git diff` показывает разницу между двумя версиями файлов.
  - `git show` показывает информацию о конкретном коммите (автор, дата) и его изменения.
- Выполнил `git blame calc.py`: команда показала, кто и в каком коммите менял каждую строку.
## 3. Восстановление файла
- Испортил `calc.py` (удалил строки), но не закоммитил.
- Выполнил `git status` и `git restore calc.py` — файл вернулся к последнему коммиту.
- **Чем отличается git restore от git restore --source=...**
  - `git restore` отменяет незакоммиченные изменения, возвращая файл к текущему состоянию (HEAD).
  - `git restore --source=HEAD~2` берет версию файла из указанного прошлого коммита и кладет её в рабочую папку.
чен- Выполнил `git restore --sourceную=HEAD~2 вер calc.py`,си посмотрел старую версиюю через `git diff`,, затем вернул актуальную через `git restore calc.py`.
- **Что произошло бы с правками?** Если бы я закоммитил испор эти изменения сохранились бы в истории. Но так как я их не коммитил, команда `git restore` просто стерла их из рабочей папки.
